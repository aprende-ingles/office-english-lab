# Office English Lab

Web estática para practicar inglés técnico de Administración y Finanzas a partir de:

- `Business administration and finance 2 ed.pdf` — Student's Book.
- `WORKBOOK.pdf` — Workbook.

## Uso local

Abre `index.html` en un navegador. No necesita instalación ni conexión para funcionar; el progreso y los borradores se guardan en el navegador del dispositivo.

## Compartir con un enlace público

Sube el contenido completo de esta carpeta (`index.html`, `styles.css` y `app.js`) a un servicio de hosting estático, por ejemplo GitHub Pages, Netlify Drop o el espacio web del centro. La página está preparada para funcionar desde la raíz del sitio sin cambiar rutas.

## Criterio de contenido

La interfaz mantiene separados Student's Book y Workbook, conserva las 20 unidades y muestra las páginas fuente en cada recorrido. Cada apartado muestra todas las actividades distintas que permite el material disponible de esa unidad, sin repetir preguntas para alcanzar una cifra fija. Las actividades interactivas se generan únicamente con el vocabulario, textos, situaciones, definiciones y expresiones de la unidad; no se han añadido temas de administración ajenos al material facilitado.
